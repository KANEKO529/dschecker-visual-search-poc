# dschecker-visual-search-poc

PoC for DSchecker visual search using DINOv3 and vector similarity search.

## Overview

This project verifies whether DSchecker can identify products using image embeddings instead of OCR-based model number recognition.

## Tech Stack

- Next.js / TypeScript
- Go / Gin
- Python
- DINOv3 ViT-S
- PostgreSQL / pgvector
- Rails API
